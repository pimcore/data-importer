# Data Importer

This package provides TypeScript support for the Pimcore Data Importer Studio integration. The registries and abstract classes are delivered via module federation at runtime.

It includes:

- TypeScript definitions for the Data Importer SDK: the registry service ids, the interpreter, loader, resolver, transformer and data target registries and their abstract classes

## Documentation

For detailed guidance on extending the Data Importer, refer to the official [Pimcore Data Importer documentation](https://docs.pimcore.com/platform/Data_Importer/).
